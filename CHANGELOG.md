# Changelog

## [1.0.1] - 2026-11-23

- Added the Wool2String crafting-table icon to every datapack ZIP and the project README.
- No recipe or compatibility changes. Manual gameplay testing remains outstanding.

## [1.0.0] - 2026-11-23

- Initial release: craft one wool block of any color into four string.
- Supports Minecraft Java 1.13–26.3, with a separate preview for 26.4 snapshots 1–10.
- Choose the ZIP for your Minecraft version, or download the All-Versions bundle and extract the matching ZIP.
- Automated recipe, format and archive validation; manual in-game compatibility testing remains outstanding.
